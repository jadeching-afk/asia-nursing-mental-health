# 精神衛生護理學國考單元練習

供亞洲大學學士後護理學系學生使用的自主練習網站。

- 863題，依16個課程單元分類。
- 每回從同一單元抽出5題，5題分別來自5個不同民國年份。
- 保留年度、考試次別、原題號與A至D原選項順序。
- 完成5題並送出後，才顯示成績、正確答案及官方更正給分說明。
- 「承上題」會附原前題情境；10題飲食障礙症依指定置於CH22延伸題。
- 練習紀錄儲存在學生自己的瀏覽器，最多100回，無姓名、學號或教師成績後台。

此儲存庫根目錄是可直接部署的靜態網站，不需安裝套件或編譯。

## iPhone 主畫面 App

用 Safari 開啟公開網址，點「分享」→「加入主畫面」；若有「以網頁 App 打開」選項，請開啟後加入。App 名稱為「精神護理國考」。這是 PWA 主畫面網頁 App，透過網址安裝，不需 App Store。

首次連網開啟並等頁尾顯示「已可離線練習」，即可離線抽題與評分。考選部外部來源連結仍需網路。練習紀錄只保存在目前 App 或瀏覽器，兩者不保證共用，也不會上傳給教師。

`manifest.webmanifest` 設定主畫面啟動、名稱與圖示；`pwa.mjs` 註冊離線服務；`sw.js` 完整快取本站題庫與介面。更新任何快取檔案時須提高 `sw.js` 的 CACHE 版本，新版本於所有現有網站／App 視窗關閉後啟用，避免中斷正在進行的練習。請勿直接刪除使用者 localStorage。

## GitHub Pages 發布

在儲存庫的 Settings → Pages，將 Source 設為 Deploy from a branch，選擇 `main` 分支與 `/(root)`，按 Save。部署完成後，以該頁顯示的網站網址提供學生使用。`.nojekyll` 保留在根目錄。

`index.html` 為入口、`styles.css` 為樣式、`app.mjs` 為介面、`quiz.mjs` 為抽題與評分規則、`bank.mjs` 為題庫。所有站內資源使用相對路徑，支援 GitHub Pages 儲存庫子路徑。更新這些檔案並提交至發布分支後，GitHub Pages 會重新發布。

題目及答案來自考選部公開試題，資料核對日115年10月20日。章節歸類與原始Word版一致。
